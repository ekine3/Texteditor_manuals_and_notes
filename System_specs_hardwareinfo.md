# Getting specs of a system

## Neofetch  
Neofetch was for a long time my favourite application to make a quick and consistent across platforms spec screen. But recently in August 2026 I realized is is now absent from APT, forcing to look up for alternatives.  
Installation:  
> apt-get install neofetch
Usage:
> neofetch  

## hw-probe  
Probe is a snapshot of your computer's hardware and system logs, intended to simplify collecting logs for investigating hardware related problems. It produces an URL.  
Installation:  
> apt-get install hw-probe
Usage:
> hw-probe -all -upload
